# Fundamentos de Java para Principiantes

## Resumen del Curso

Curso introductorio de programación en Java para estudiantes de secundaria. La ruta comienza con un primer programa, continúa con variables, decisiones y bucles, e introduce la programación orientada a objetos y la depuración.

- **Duración total:** 1 h 00 min 28 s.
- **Público objetivo:** estudiantes de 12 a 17 años sin experiencia en programación.
- **Prerrequisitos:** ninguno.
- **Herramientas necesarias:** navegador web.
- **Repositorio de código fuente:** [java-fundamentals-course-blip](https://github.com/1ASI0729-7800-BLIP/java-fundamentals-course-blip).
- **Lista de reproducción:** (https://www.youtube.com/playlist?list=PLImLkHTRPdQk) (no listada).

## Secuencia de las lecciones

### Lección 1 · Introducción a Java y a la programación (3:35)

- **Descripción:** primer acercamiento a Java mediante un programa que muestra un mensaje en consola.
- **Enlace:** [Ver la lección en YouTube](https://youtu.be/XqZCOL2uWNY).
- **Conclusiones clave:** un programa ejecuta instrucciones y puede mostrar resultados en la consola.
- **Práctica:** reproducir el primer programa de la lección.

### Lección 2 · Variables, tipos de datos y entrada por consola (10:51)

- **Descripción:** uso de variables para guardar datos y lectura de información desde la consola.
- **Enlace:** [Ver la lección en YouTube](https://youtu.be/03T24AsZ5JA).
- **Conclusiones clave:** cada variable tiene un nombre y un tipo que determina qué valor puede almacenar.
- **Práctica:** crear una ficha que muestre un nombre y una edad.

### Lección 3 · Decisiones y bucles (13:16)

- **Descripción:** introducción a las estructuras que permiten tomar decisiones y repetir instrucciones.
- **Enlace:** [Ver la lección en YouTube](https://youtu.be/YuCrwRrD_zQ).
- **Conclusiones clave:** una condición controla qué instrucciones se ejecutan y un bucle permite repetirlas.
- **Práctica:** seguir los ejemplos de decisiones y bucles del video.

### Lección 4 · Métodos y clases (14:59)

- **Descripción:** introducción a los métodos y a la organización del código en clases.
- **Enlace:** [Ver la lección en YouTube](https://youtu.be/zqYMIezvBpk).
- **Conclusiones clave:** los métodos agrupan instrucciones que pueden reutilizarse.
- **Práctica:** seguir el ejercicio mostrado en el video.

### Lección 5 · Encapsulación y mascota virtual (14:31)

- **Descripción:** construcción de un simulador sencillo de mascota virtual.
- **Enlace:** [Ver la lección en YouTube](https://youtu.be/nf9LgB1jcpI).
- **Conclusiones clave:** los atributos privados permiten controlar cómo se accede a los datos de un objeto.
- **Proyecto final:** reproducir el simulador de mascota virtual mostrado en el video.

### Lección 6 · Depuración y próximos pasos (3:15)

- **Descripción:** lectura de mensajes de error y corrección de errores de sintaxis.
- **Enlace:** [Ver la lección en YouTube](https://youtu.be/ZiywmC8OJ1k).
- **Conclusiones clave:** el mensaje del compilador indica el tipo de error y ayuda a localizar la línea que debe revisarse.
