# Fundamentos de Java para principiantes

## Resumen del curso

Curso introductorio de programación con Java para estudiantes de secundaria de **12 a 17 años**, sin experiencia previa. La ruta de aprendizaje aborda conceptos básicos y programación orientada a objetos mediante ejemplos cotidianos y actividades en el navegador.

- **Duración objetivo:** aproximadamente 60 minutos. La duración total de las grabaciones actuales todavía no está verificada.
- **Formato de entrega:** entre 5 y 10 lecciones de 5 a 15 minutos cada una.
- **Prerrequisitos:** ninguno.
- **Herramientas para estudiantes:** navegador web y editor de Java gratuito en línea. No se requiere instalar Java, un IDE ni herramientas locales.
- **Código fuente:** [java-fundamentals-course-blip](https://github.com/1ASI0729-7800-BLIP/java-fundamentals-course-blip).
- **Grabaciones de respaldo:** [carpeta de Drive](https://drive.google.com/drive/folders/1Yn96Fp4Ed8tmh89XncpW5xWSx8_3t4F_).

> **Estado de preparación:** se enlazan temporalmente cinco grabaciones de Drive por indicación del equipo. La versión final debe usar videos de YouTube no listados. Las carpetas de prácticas y guiones están preparadas, pero aún no contienen los archivos originales usados en las grabaciones. Este documento no acredita el cumplimiento completo de la actividad.

## Cómo seguir el curso

1. Abre las grabaciones en el orden de los módulos.
2. Abre el editor en línea utilizado en la lección. Las vistas previas muestran JDoodle y OnlineGDB.
3. Pausa la explicación cuando aparezca una actividad y ejecuta el código por tu cuenta.
4. Compara el resultado con el ejemplo resuelto correspondiente, cuando el equipo incorpore esos archivos.

Accesos generales: [JDoodle](https://www.jdoodle.com/online-java-compiler) y [OnlineGDB](https://www.onlinegdb.com/online_java_compiler). Estos accesos **no son prácticas precargadas**; deben sustituirse o complementarse con los enlaces compartidos de los ejercicios reales. Comprobar la experiencia gratuita y los permisos de cada práctica antes de entregar.

## Objetivos de aprendizaje y cobertura por completar

El enunciado exige los siguientes temas. Esta tabla es una lista de comprobación, **no una afirmación de que las grabaciones ya cubran todo el contenido**.

| Tema requerido | Qué debe poder hacer el estudiante | Evidencia que falta registrar |
|---|---|---|
| Introducción a programación y Java | Explicar para qué sirve un programa y ejecutar un ejemplo sencillo. | Lección y minuto. |
| Variables y tipos | Declarar y usar variables como `int` y `String`. | Lección, minuto y práctica. |
| Operadores y expresiones | Calcular y comparar valores. | Lección, minuto y práctica. |
| Condicionales | Elegir un comportamiento con `if` y `else`. | Lección, minuto y práctica. |
| Bucles | Repetir acciones con `for` y `while`. | Lección, minuto y práctica. |
| Métodos y parámetros | Reutilizar instrucciones y recibir valores. | Lección, minuto y práctica. |
| Entrada y salida | Leer datos con `Scanner` o consola y mostrar resultados. | Lección, minuto y práctica. |
| Clases, objetos y constructores | Crear una clase e instanciar objetos con atributos y métodos. | Lección, minuto y ejemplo resuelto. |
| Encapsulación | Proteger atributos y usar getters/setters. | Lección, minuto y ejemplo resuelto. |
| Arrays o cadenas con objetos | Manipular una estructura sencilla dentro de un programa. | Lección, minuto y práctica. |
| Programa integrador | Completar un programa básico basado en POO. | Código inicial, solución y ejecución. |
| Buenas prácticas y errores comunes | Reconocer, explicar y corregir errores de principiante. | Lección, minuto y ejecución corregida. |
